> 只记**已确认**决策；未定的留在 `PROJECT.md` §6 待拍板，不在此处预写。

## 0. 记录规则（固定，勿删）

1. 每条决策有唯一 ID `D-xxx`，按时间顺序只增不改；被翻案时新开一条并写“取代 D-xxx”。
2. 每条必须含：轮次、决策、背景/选项、理由、影响面、编制、状态。
3. 编制每轮在此重定，并同步更新 §2 时间线；安全门控 run 的 SAFETY 必须单列。
4. 终止/达成的最终决定也必须是一条 `D-xxx`（状态：终止/达成）。
5. **关闭收口 + 跨轮承接**：关闭/终止类 `D-xxx` 必须写明资产去向；跨轮/跨 run 承接项必须写 owner + 去向 + 最晚复核轮；已知游离项无 owner/去向时，必须有主会话在此处显式接受，否则不得关闭。
6. 安全相关决策必须引用 `safety/` 账本或 `hdrive_gate.py status --json` 的数字，不得只写“已确认安全”。
